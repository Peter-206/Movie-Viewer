# Security

Only the latest source revision is maintained. There is no promise of a response time or long-term support.

Do not post credentials, private catalogs or exploitable security details in public issues. Use the repository's Security tab to report a vulnerability privately if private reporting is enabled. If it is unavailable, open an issue asking the maintainer for a private contact method without including the vulnerability details.

Use a copy of your collection when testing. Startup and Rescan rename the selected main video to `movie` with its existing extension. Back up your library and database before upgrading.
